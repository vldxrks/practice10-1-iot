## Запуск на Android
Установіть Flutter SDK та Android SDK, створіть емулятор у Android Studio.
З каталогу проєкту виконайте:
```sh
flutter create --platforms=android --project-name practice10 .
flutter pub get
dart format lib
flutter analyze
flutter run
```
Команда create додає платформні файли до підготовленого вихідного коду.
Якщо вона створила test/widget_test.dart для стандартного лічильника, видаліть цей шаблонний тест: він не відповідає цьому застосунку.

## Перевірка
Flutter та Dart SDK завантажені, однак Dart VM аварійно завершується у цьому середовищі
(Failed to retrieve stack bounds). Компіляція, аналізатор, запуск і тести на Android
не виконані. Результат цих команд потрібно перевірити локально.
Збережіть вивід команд і фактичні знімки екрана в docs/.
У методичках потрібне посилання на GitHub, а для робіт 9.1 і 9.2 також відео.
Репозиторій, відео й історія комітів до цього архіву не входять.

## Архітектура
lib/main.dart — запуск та інтерфейс; моделі, повторно використовувані віджети
й робота зі сховищем винесені в окремі файли.
Помилки сховища відображаються користувачу. Контролери введення звільняються.

## Реалізація
Book і BookRepository; SQLite з індексом author; додавання, читання, оновлення статусу, видалення. Пошук, фільтри, сортування, статистика. Окреме файлове сховище не потрібне для варіанта 1 — SQLite вже зберігає базу у файлі.
